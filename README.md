# Lakstraat Logboek

Logboek voor de lakstraat van Houtindustrie Ideaal: per lakdag de begin- en eindstand van elke wals, temperatuur, luchtvochtigheid en bijzonderheden.

- App: https://flapser66.github.io/lakstraat/
- Gegevens staan in Firebase (project `lakstraat-logboek`, Firestore in europe-west4).
- `firestore.rules` bevat de beveiligingsregels zoals ze in de Firebase-console staan.
- Beheerder: ingesteld in `config.js` én `firestore.rules`.
